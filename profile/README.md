# Trivial.si

**Trivial Superintelligence** builds software and works alongside teams on AI-assisted data engineering. We develop Sljeme, our platform for data delivery, and share useful tools as open source.

## Open source

### [hs](https://github.com/trivial-si/hs)

Local time tracking, tasks, and focus sessions for your terminal. Written in Rust. Inspired by Project Hamster.

[Get started](https://github.com/trivial-si/hs#readme) · [Contribute](https://github.com/trivial-si/hs/blob/main/CONTRIBUTING.md) · [Ask a question](https://github.com/trivial-si/hs/discussions)

Bug reports, documentation, testing, design, and code are welcome. Each project explains its scope, license, and contribution process. Please follow our [code of conduct](https://github.com/trivial-si/.github/blob/main/CODE_OF_CONDUCT.md).
